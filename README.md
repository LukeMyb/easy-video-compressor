# Easy Video Compressor

Discordにアップロードするために、動画ファイルのサイズを自動的に10MB以下（目標9.0MB）に圧縮するシンプルなPythonスクリプトです。

## 前提条件

このスクリプトは内部でFFmpegを使用しています。以下の実行ファイルを `bin` フォルダ内に配置してください。

- `bin/ffmpeg.exe`
- `bin/ffprobe.exe`

## ディレクトリ構成

```text
easy-video-compressor/
├── bin/          # ffmpeg.exe, ffprobe.exe を配置するフォルダ
├── input/        # 一括圧縮したい元の動画を入れるフォルダ
├── output/       # 一括圧縮された動画が出力されるフォルダ
├── scripts/      # 実行用バッチファイル群
│   ├── compress_all.bat        # inputフォルダの一括処理用
│   ├── compress_clipboard.bat  # クリップボードのパスを処理用
│   ├── add_context_menu.bat    # 右クリックメニューへの登録用
│   ├── remove_context_menu.bat # 右クリックメニューからの削除用
│   └── run_context_menu.bat    # （内部用）右クリックメニューからの実行処理
└── src/
    └── main.py   # 実行スクリプト
```

## 使い方

用途に合わせて3つの方法で動画を圧縮できます。

### 方法1: 右クリックメニューから圧縮（おすすめ）
動画ファイルを右クリックして直接圧縮できる最も便利な方法です。

1. **初回準備**: `scripts/add_context_menu.bat` を実行してメニューに登録します。
2. 圧縮したい動画ファイル（`.mp4`等）を右クリックします。
   （※Windows 11の場合はメニュー下部の「その他のオプションを確認」をクリック）
3. **「Compress for Discord」** を選択します。
4. 元の動画と**同じフォルダ内**に `元のファイル名_compressed.mp4` が出力されます。
   （※元に戻したい場合は `scripts/remove_context_menu.bat` を実行してください）

### 方法2: クリップボードから指定して圧縮
ファイルのパスをコピーして指定する方法です。

1. 圧縮したい動画ファイルの上で `Shift` + 右クリックし、「パスのコピー」を選択します。
2. `scripts/compress_clipboard.bat` を実行します。
3. 元の動画と**同じフォルダ内**に圧縮された動画が出力されます。

### 方法3: フォルダを使った一括圧縮
複数の動画をまとめて圧縮したい場合に便利な従来の方法です。

1. `input` フォルダに圧縮したい動画ファイルを入れます。
2. `scripts/compress_all.bat` を実行します。
3. `output` フォルダ内に圧縮された動画が出力されます。

## 仕様
- 2パスエンコード処理で画質をできるだけ保ちながら圧縮します。
- 目標サイズは安全マージンを取って9.0MBに設定されています。
- オーディオビットレートは128kbpsに固定されています。
- 動画が長すぎて10MB以下に圧縮できない（映像ビットレートが0以下になる）場合はエラーメッセージを表示してスキップします。
